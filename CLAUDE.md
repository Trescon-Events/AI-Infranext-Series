# CLAUDE.md - AI InfraNext Series Guidelines

See `AGENTS.md` and `BUILD-SPEC.html` for complete brand conventions and deployment instructions.

## Key Development Rules
- Static HTML5, zero runtime framework dependencies.
- Alternating Dark Navy (`#132F4B` / `#0B1E33`) and Light Cloud Wash (`#F6F9FC` / `#FFFFFF`) sections.
- Run `node tools/validate-series.js` before deploying to verify HTML tag balance and brand compliance.
- Strictly adhere to the AI InfraNext naming rules (closed-up compound, capital 'N', no 'the' prefix).
- Never use "By invitation only".
